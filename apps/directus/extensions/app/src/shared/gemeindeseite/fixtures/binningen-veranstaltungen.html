Veranstaltungen

Planen Sie eine Veranstaltung in Binningen?

Sie können diese kostenlos hier eintragen lassen. Melden Sie uns Ihren Anlass einfach per E-Mail an infoNULL@binningen.bl.ch.

Veranstaltungen wie Quartierfeste, Umzüge, Sportveranstaltungen usw. auf öffentlichem Grund sind bewilligungspflichtig. Weitere Informationen zum Bewilligungsverfahren finden Sie hier.
